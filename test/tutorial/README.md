# Tutorial Examples

This directory contains a small set of Lox programs that demonstrate the features listed in the project README.

Files:

- 01_language_basics.lox
- 02_functions_and_closures.lox
- 03_classes_and_inheritance.lox
- 04_containers.lox
- 05_file_io.lox

Run any example with:

```sh
bin/lox test/tutorial/01_language_basics.lox
```
