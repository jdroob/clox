# clox

A C implementation of the Lox language interpreter from Bob Nystrom's "Crafting Interpreters".

## Project structure

- `src/` - C source files for the scanner, compiler, VM, and runtime.
- `include/` - public headers used during compilation.
- `test/` - Lox program examples organized by chapter.
- `bin/` - output directory for the built `lox` executable.
- `obj/` - object files generated by `make`.

## Build

From the repository root:

```sh
make
```

This produces the interpreter at `bin/lox`.

### Debug builds
- `make view_stack`
- `make debug`
- `make debug_scanner`
- `make debug_chunk`
- `make debug_gc`
- `make debug_stress_gc`
- `make debug_log_gc`
- `make debug_chunk_jrmalloc`
- `make debug_jrmalloc`

## Run

Start the interactive REPL:

```sh
bin/lox
```

Run a Lox source file:

```sh
bin/lox test/tutorial/01_language_basics.lox
```

See list of built-in functions:

```python
help();
```

## Features

This implementation follows the Lox language chapters from "Crafting Interpreters" (plus some additional features) and includes:

- REPL and script execution modes
- Scanner and parser for Lox syntax
- Bytecode compiler and VM
- Local and global variable support
- `final` variables
- Control flow: `if`, `else`, `while`, `for`, `switch`
- Short-circuit logic with `and` / `or`
- Ternary expressions
- Functions, call frames, and returns
- Native functions and runtime integration
- File I/O helpers for reading and writing files
- Classes and inheritance
- Containers: lists, maps, more to come.. ?

## Notes

- The interpreter uses a custom `Makefile` and compiles with `cc`.
- Runtime and compile errors are reported with proper exit codes.
- The implementation is based on chapter progression through the book, with sample programs in `test/`.
